Tạo API Token Xác Thực Mới

API Token được tạo riêng biệt với phiên đăng nhập Web Dashboard, lưu trữ vào DynamoDB và dùng để gọi trực tiếp các dịch vụ qua AWS API Gateway (Edge-Optimized).

API Token của bạn đã được khởi tạo thành công!
Vui lòng sao chép token ngay bây giờ. Token này sẽ được sử dụng trong header Authorization: Bearer <TOKEN>.

Hướng Dẫn Gọi AWS API Gateway (Edge-Optimized)

Endpoint đã được tối ưu hóa toàn cầu qua mạng CloudFront Edge. Sử dụng lệnh cURL sau để gửi sự kiện vào Amazon EventBridge:

curl -X POST "https://oqp7jmg7je.execute-api.ap-southeast-2.amazonaws.com/prod/events" \ -H "Authorization: Bearer <YOUR_API_TOKEN>" \ -H "Content-Type: application/json" \ -d '{ "source": "xregion.backend.instance", "detailType": "Instance Lifecycle Request", "detail": { "action": "START", "instance_id": "78cfad73-d7f7-49ff-8bcc-446d7c2f538d", "instance_name": "test1" } }'
